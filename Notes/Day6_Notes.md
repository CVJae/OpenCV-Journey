# Day 6 Notes – Color Detection

## What I Did
- Loaded an image using OpenCV
- Converted the image from BGR color space to HSV
- Defined a color range to detect
- Created a mask to isolate pixels within that color range
- Displayed the masked result showing detected colors

## What I Learned
- HSV color space separates color information from brightness
- Detecting colors is easier in HSV compared to BGR
- Masks allow us to filter parts of an image based on color
- Color detection is used in robotics, object tracking, and automation systems
- Masking is a fundamental technique used in many computer vision tasks

## Key Concepts
- HSV color space
- Color masking
- Image filtering
- Color-based object detection
