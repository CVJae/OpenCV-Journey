# Day 5 Notes – Contour Detection

## What I Did
- Loaded an image using OpenCV
- Converted the image to grayscale
- Applied Gaussian blur to reduce noise
- Used Canny edge detection to find edges
- Detected contours from the edge-detected image
- Drew contours around detected shapes

## What I Learned
- Contours represent boundaries of objects in images
- Edge detection helps identify where contours exist
- OpenCV can detect contours using the findContours() function
- Contours can be drawn on images to visualize detected shapes
- Contour detection is used in object detection, shape analysis, and motion tracking

## Key Concepts
- Contours
- Edge detection
- Shape detection
- Image preprocessing
