# Day 1 Notes

## What I Did
- Loaded an image using OpenCV
- Inspected the image by printing its shape
- Checked the pixel value of the top-left pixel
- Converted the image to grayscale and displayed it
- Loaded a video file and extracted the first 10 frames

## What I Learned
- Images in OpenCV are stored as arrays (height, width, color channels)
- Each pixel contains color values (BGR in OpenCV)
- The .shape attribute tells you the image dimensions
- Video files can be read frame-by-frame like a sequence of images
