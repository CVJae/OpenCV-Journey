# Day 4 Notes – Video Processing

## What I Did
- Loaded a video file using OpenCV
- Processed the video frame by frame
- Converted each frame to grayscale
- Displayed both the original video frames and the grayscale frames
- Learned how to stop the video processing loop using a key press

## What I Learned
- Videos are processed as sequences of images called frames
- OpenCV uses VideoCapture to load and read videos
- Each frame of a video can be processed like a normal image
- Real-time computer vision systems analyze frames continuously
- Converting frames to grayscale reduces complexity for further processing

## Key Concepts
- VideoCapture
- Frame processing
- Real-time video analysis
- Grayscale conversion
