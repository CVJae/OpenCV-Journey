# Day 3 Notes – Edge Detection

## What I Did
- Loaded an image with OpenCV
- Converted the image to grayscale
- Applied Gaussian blur to reduce noise
- Used the Canny edge detection algorithm to detect edges in the image
- Displayed the detected edges

## What I Learned
- Edge detection helps identify boundaries of objects in images
- Converting images to grayscale simplifies processing
- Blurring an image helps remove noise before detecting edges
- The Canny edge detector is commonly used in computer vision pipelines
- Edge detection is often used before contour detection and object recognition

## Key Concepts
- Grayscale conversion
- Gaussian blur
- Canny edge detection
- Feature extraction
