# Day 2 Notes – Image Transformations

## What I Did
- Loaded an image using OpenCV
- Displayed the original image
- Resized the image to a different resolution
- Cropped a section of the image
- Flipped the image horizontally

## What I Learned
- Images can be resized using OpenCV's resize() function
- Cropping an image can be done using array slicing
- Images in OpenCV behave like NumPy arrays
- Flipping images can help with data augmentation when training machine learning models
- Image transformations are important for preparing data before training computer vision models

## Key Concepts
- Image resizing
- Cropping using array slicing
- Image flipping
- Image preprocessing
